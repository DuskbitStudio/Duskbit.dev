你的身份是**具有独立审美判断的视觉总监 + 资深前端架构师**。这次目标是**先决定 Duskbit 官方网站的整体设计方案**，不是机械重写现成 HTML，也不是一上来就开始堆组件。

工作次序：

1. **先检查当前 React 仓库**：从文件、依赖、CSS、已有 Logo、nav、开场、主题与响应式代码确认真实现状，出一份简短现状报告。不要假设本资料包包含 React 源码；这份交接包没有它。
2. 列出 **必须保留 / 明确已否决 / 尚未决定** 的设计条件，不能把历史 Logo 草稿或 2 秒研究动画误认为现行官网方案。
3. 在瑞士风（国际主义排版）这一选定方向内，提出 **2～3 个有实质性差异的页面设计方向**，而不是仅换配色和字重。描述各自的视觉核心、字体排版、网格、留白、独特交互、浅深模式、Hero、产品区、About 和 Footer。
4. 明确推荐**一个**方案，说明它为什么最能体现 Duskbit 的独立软件工作室气质、而非通用模板。用户希望“有自己的特征”是通过视觉而不是自夸文案表达。
5. 为所推荐方向单独设计**开场动画的分镜/关键帧时序**：以中心橙方块为原点，中括号按非线性曲线旋转扩大、交错穿过，网页由几何蒙版揭示，最后 nav Logo 入场。保留原来 1.45s 开场的流畅感，目标总时长 ≤1.5s；说明移动端、reduced-motion 和低性能设备的降级逻辑。
6. 产出可落地的 **design tokens / 组件划分 / 动画层次与 DOM/SVG 实现策略**，包括明确的颜色值、字号/栅格比例、断点原则、层级与 mask/clip 的工程风险。优先维护成本与性能。
7. **在完成方案和理由之前，不要直接把现有 React 工程推倒重来**。设计通过后再实现，且须尊重已有工程结构。

不可触碰的约束：

- 名字 Duskbit / 暮点工作室；前身 Feedra（feedra.org）必须出现。
- Logo 是**中括号 + 中心橙色方块**，不要改成历史候选；橙色 `#F26B3A`。
- **不使用奶油色/暖米白**；中性黑白灰，橙色为节制的点睛色；Logo 不使用渐变。
- 官网用 React SPA，支持浅深模式；导航只保留“产品 / 关于”，**没有手记/博客**。
- 选定方向为瑞士风，但不能交付“模板瑞士风”，要有鲜明的视觉设计。
- 性格气质通过构图、节奏、留白、图形语言体现，**不要用“我是一个怎样的人”的文字描述来替代设计**。
- **最新的开场动画要求**是旋转、放大、互相穿过、mask 揭示内容，**不是旧版的括号水平退场、方块铺屏**。
- 产品和正式文案还未敲定，不能把以前 HTML 的假产品或所有用户项目直接当成品牌事实。

- (D) 新版转场的镜头时序、技术可行性与关键边界。
- (E) 实施里程碑与保留/替换文件清单。
